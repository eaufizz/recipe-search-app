# UI direction

## References

| Reference | Useful patterns | Fit | Difficulty | Adopt | Do not adopt |
| --- | --- | --- | --- | --- | --- |
| [SuperCook](https://www.supercook.com/) | Ingredient-first pantry and a direct path to matching recipes | Very high | Medium | Ingredient chips, visible pantry count, prominent recipe search action | Voice input and a very large category taxonomy |
| [Samsung Food](https://samsungfood.com/) | Clear recipe-card hierarchy, search and mobile bottom navigation | High | Medium | Recipe metadata order, bottom navigation, search and sort controls | Community, nutrition and photography-heavy presentation |
| [Bring!](https://www.getbring.com/en/features/personalized) | Large tiles, quick list editing and optional item details | High | Low | Generous tap targets, lightweight selection and optional quantity details | Advertising, shared-list and shopping-specific features |

## Selected direction

The app combines SuperCook's ingredient-first flow, Samsung Food's recipe-card hierarchy and bottom navigation, and Bring!'s lightweight tile interactions. The implementation is original and uses no copied code, images, icons or paid assets.

The visual language uses a warm canvas, deep leafy green for primary actions and a restrained tomato accent. Content is ordered for one-handed mobile use: current pantry state first, relevant choices second, and a persistent primary action near the bottom. Status is communicated with text and icons as well as color.
